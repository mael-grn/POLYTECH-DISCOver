# DISCOver
Projet universitaire - Polytech Lyon - informatique 3A

---

DISCOver est une application ayant pour but de permettre à un utilisateur de calculer la probabilité qu'une musique (ou tous type de fichier audio) devienne populaire.

Elle est composée de deux parties :
- **frontend** : Une application flutter adaptés aux écrans large (desktop) comme petit (smartphone).
- **backend** : Une api flask permettant d'accéder aux fonctionnalités principales, ainsi qu'au modèle de machine learning préalablement entrainé.

Afin de pouvoir executer chaque parties de l'application, vous pouvez vous renseigner auprès des readme correspondant à chaque partie.
